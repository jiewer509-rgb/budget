# 生活账本 · Budget

一款面向个人日常使用的消费预算网页：记录收支、看清生活成本、安排基本生活与额外消费。以手机操作为主，也提供宽屏布局。

这是一个从个人需求出发、通过实际使用持续迭代的作品。产品需求、功能取舍和使用反馈由作者主导，代码实现与迭代使用 AI 辅助。

## 能做什么

- **收支记录**：金额计算、类别选择、备注、历史记录搜索、日期筛选与编辑。
- **月度预算**：固定和周期类别预算汇总到基本生活池；额外消费共用剩余总额度，不逐类限制。
- **按天分摊**：跨月费用设置起止日期，按覆盖天数计入各月；估算费用再次发生时提醒核对。
- **收支汇总**：月度／年度分类结构与收入支出柱状图，明细按需展开。
- **类别管理**：在记账时新建、修改、停用或恢复类别，保留已有记录。
- **外观设置**：复古美式、莫兰迪、鲜艳跳脱、纯色酷炫，也可自定义颜色。
- **本地保存与备份**：IndexedDB 保存，支持 JSON 导入／导出和回收站。

## 快速开始

无需安装前端依赖或构建工具。使用任意静态服务器打开项目，例如：

```bash
python3 -m http.server 8080
```

浏览器访问 `http://localhost:8080`。手机与电脑在同一局域网时，可使用电脑的局域网 IP 访问。也可将此仓库部署到 GitHub Pages 或其他静态网站托管服务。

- `index.html`：主入口
- `mobile.html`：手机布局
- `desktop.html`：宽屏布局

首次打开是空账本，先在预算页设置本月总额度，再填写基本生活类别预算。默认总预算为 0，未包含作者个人预算。

## 预算与统计口径

基本生活的基础额度为有效的固定、周期类别预算之和；额外消费的基础额度为月总预算减去基本生活。可在池子间手动调拨，月总额不变；类别合计变化后重新分配，旧调拨保留为历史。

生活成本按使用日期分摊，实际付款按付款日期统计，二者可能不同。按天平均分摊不等于运营商等服务商的实际每日扣费。投资买入、账户转账和还款本金不应当记成生活消费；此项目没有完整的资产或负债账户体系。

## 数据与隐私

**仓库只保存程序，不保存真实账单。** 没有嵌入作者的交易记录、个人预算、账户资料或私人账本页面；没有服务器账户、云端账单数据库或跨设备同步功能。

使用时的数据保存在当前网站来源下、当前浏览器的 IndexedDB。清除浏览器数据可能丢失记录；更换浏览器、设备、域名或协议不会自动迁移。请定期导出 JSON 备份，并妥善保存到自己的设备。不要将导出的账单提交到公开仓库。

公开仓库和网页源码不适合放置真实账单；即使文件被忽略，也请在提交前检查暂存区。

## 技术与项目结构

原生 HTML、CSS、JavaScript，无框架、无运行时第三方依赖。

| 文件 | 作用 |
|---|---|
| `app.js` / `app.css` | 基础状态、数据存储、记账与页面样式 |
| `pools.js` | 基本生活／额外消费预算与调拨 |
| `daily-coverage.js` | 按天分摊与估算核对 |
| `inline-categories.js` | 类别编辑与停用 |
| `review.js` / `clarity.js` | 汇总与图表 |
| `compact.js` / `responsive.js` | 明细折叠、分页与响应布局 |
| `appearance.js` | 配色预设、自定义和保存 |
| 其他 CSS / JS | 各轮功能与视觉迭代模块 |

目前使用多个按顺序加载的模块覆盖基础函数，这是渐进迭代的结构；后续可进一步合并职责、减少覆盖关系。修改脚本加载顺序需要检查相关交互。

## 检查

需要 Node.js（仅用于开发检查）：

```bash
node scripts/check.cjs
```

检查脚本语法、入口资源引用、空账本默认状态和敏感数据残留。本仓库检查不代表完整端到端或手机实机测试。
